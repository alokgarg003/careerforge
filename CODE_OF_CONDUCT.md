# Code of Conduct

This repository should stay respectful, constructive, and welcoming.

## Expected Behavior

- Be respectful in issues, pull requests, and discussions
- Focus feedback on the work, not the person
- Share context and examples when suggesting changes

## Unacceptable Behavior

- Harassment, threats, or personal attacks
- Discriminatory or abusive language
- Repeated disruptive or bad-faith behavior

## Reporting

If you see behavior that does not align with this code of conduct, report it privately to `alokgarg003@gmail.com`.
